# TaskForge.SDK

The .NET 10 SDK for TaskForge provides an HTTP client, typed job handlers, and a
hosted worker. Use the SDK to submit jobs, inspect results, or run handlers in
your application.

Install `TaskForge.SDK` from the local folder containing the `.nupkg`. Use
NuGet.org for its third-party dependencies. See the [SDK usage guide](https://github.com/Arvence/TaskForge/blob/main/docs/dotnet-client.md).
